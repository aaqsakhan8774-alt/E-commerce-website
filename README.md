# E-commerce Website

A multi-page front-end for an online course/e-commerce platform, built with
HTML, CSS, and JavaScript.

## Pages

- Home / course catalog
- Course detail pages
- Instructor listing
- Login / signup
- Cart and checkout flow
- About and contact pages

## Tech Stack

HTML5, CSS3 (with SCSS sources), vanilla JavaScript, Bootstrap-based layout.

## Running Locally

Open `index.html` directly in a browser, or serve the folder with any static
file server (e.g. `npx serve .`).
